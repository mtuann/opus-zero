# Mẫu ghi chép

Sao chép khối dưới đây vào một file mới trong `docs/nghe-nhac/` (ví dụ `mozart-40.md`), điền thông tin, rồi thêm trang vào mục `nav` trong `mkdocs.yml`.

```markdown
# Tên nhà soạn nhạc: Tên tác phẩm

| | |
|---|---|
| Nhà soạn nhạc | |
| Năm sáng tác | |
| Thời kỳ | |
| Thể loại | |
| Giọng | |
| Bản thu đã nghe | Nghệ sĩ / dàn nhạc, năm thu, link |

## Lần 1 — Cảm nhận
(Vui/buồn? Căng thẳng/êm dịu? Đoạn nào thích nhất, ở phút thứ mấy?)

## Lần 2 — Giai điệu chính
(Giai điệu nào nhớ được? Nhạc cụ nào chơi? Xuất hiện ở đâu?)

## Lần 3 — Cấu trúc
(Sơ đồ A B A… kèm mốc thời gian)

## Lần 4 — So sánh bản thu
(Bản thu thứ hai là của ai? Khác gì? Thích bản nào hơn, vì sao?)

## Bối cảnh
(Vài dòng về hoàn cảnh sáng tác, đọc từ nguồn đáng tin)

## Nghe tiếp
(Tác phẩm liên quan muốn nghe sau)
```
